# 🍽️ LLM Restaurant Name Generator

An AI-powered Restaurant Name & Menu Generator built using:

- 🧠 Local LLMs via Ollama
- 🔗 LangChain
- 🎨 Streamlit
- 🐍 Python

The application generates:
- Fancy restaurant names
- Creative menu items

based on selected cuisine types like Indian, Italian, Mexican, Arabic, etc.

Runs fully offline using local LLM models such as Gemma 3 and Llama 3.
